Verified NEAR Mainnet deployment & safeguards

2. Key Safeguards

  • NEP-413 Cryptographic Wallet Sessions: Wallet authentication is verified cryptographically with anti-impersonation checks.
  • Preview-Before-Pay: Full deliverable downloads remain locked until on-chain settlement is confirmed.
  • OutLayer TEE Attestation: Completed deliverables are attested via OutLayer WASM execution and bound to a SHA-256 evidenceHash.
  • Configurable Spending Policy & Beta Cap: Autonomous x402 micro-spends enforce per-job budget caps and auto-approve thresholds, with Beta Phase escrows capped at $1.00 USDC/job.

3. Responsible Disclosure

If you discover a security vulnerability in SnowMoon's smart contracts or backend, please report it responsibly via github.com/zaxcrypto/SnowMoon before public disclosure.
